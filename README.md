# Community Launch Kit · 社区推广助手

给 AI 一段产品介绍，让它找出 Reddit、Facebook 上的真实需求，整理 **10 条具体需求帖**，并准备对应的文案、配图和发布位置。

适合独立开发者和小团队找第一批用户。这是给 AI 助手使用的 Skill，包含工作流程和本地结果检查脚本。运行它的助手需要联网搜索和网页阅读能力；生成配图还需要图片工具。

## 你会拿到什么

- 需求帖链接、用户在问什么、产品能帮哪一部分。
- 社区规则依据，以及应该回复原帖、发新帖，还是去专门的推广帖。
- 适配每条需求的文案，写明自己是产品开发者。
- 适合发布位置的图片和说明；不能配图时说明原因。
- 可点击的 HTML 清单，以及表格软件可打开的 CSV。

**10 条需求不一定等于 10 个允许推广的位置。** 找不到足够的真实帖子，就报告实际数量。Facebook 私密群、登录后才可见的内容和未核实的规则会标为待检查。默认准备材料，不自动发帖、私信或加入群组。

## 安装

已安装 Node.js 的用户可使用 [Skills CLI](https://github.com/vercel-labs/skills)：

```sh
npx skills add zhangskiiiii-commits/community-launch-kit --skill community-launch-kit
```

按提示选择自己的 AI 工具。安装器的 Node.js 要求以官方说明为准。

也可以下载仓库，将 `skills/community-launch-kit` 整个目录放进自己的 AI 工具支持的 Skills 目录。不要只复制 `SKILL.md`，它会使用同目录下的参考文件和检查脚本。

## 直接这样说

```text
使用 $community-launch-kit。
这是我的产品：[网址或介绍]
现在已经能做到：[2–3 个真实功能]
目标用户：[人群、国家、语言]
当前阶段：[内测/已上线]；价格或试用：[知道就填]
希望用户下一步：[试用/下载/反馈]
可用截图或素材：[文件，或者暂时没有]

请搜索 Reddit 和 Facebook，找 10 条真实具体的需求帖。
记录链接、问题、产品可以帮助的部分，核对社区规则。
生成对应文案和适合发布的配图，告诉我在哪里发、怎么发。
不要自动发布；不足 10 条就如实说明，输出到我指定的工作目录。
```

不清楚所有信息也可以先给产品介绍，Skill 会先做能做的部分。输入模板见 [examples/product-brief.md](examples/product-brief.md)。

## 输出长什么样

| 字段 | 内容 |
| --- | --- |
| 需求来源 | 具体帖子链接、标题、时间、实际读到的问题 |
| 产品适配 | 能解决什么，以及不能解决什么 |
| 规则证据 | 规则链接、核查时间、推广/链接/图片要求 |
| 发布位置 | 回复原帖 / 发新帖 / 专门推广帖 / 暂不发布 |
| 文案与图片 | 可复制文案、图片文件或未完成说明 |
| 状态 | 可作为发布建议 / 待检查 / 跳过 |

每次运行独立保存 `campaign.json`、需求表、文案、图片、搜索记录和复核页面。真实客户资料、私密群内容和账号信息不会作为公开仓库的示例。

## 检查与导出

需要 Python 3.10 或以上，无第三方 Python 依赖。在仓库根目录运行：

```sh
python skills/community-launch-kit/scripts/check_campaign.py /path/to/run/campaign.json --render review
```

结果在该次运行目录的 `review/index.html` 和 `review/opportunities.csv`。字段说明见 [output-schema.md](skills/community-launch-kit/references/output-schema.md)。相对 `--render` 路径以 `campaign.json` 所在目录为准。导出不会覆盖已有审核文件，再次导出请换一个新目录，如 `review-v2`。旧背景帖另计，不充当近期达标数量；同一图片文件也不会重复计数。

检查脚本能发现重复帖子、规则状态冲突、错误图片路径和引用不到的产品事实。它不能代替阅读网页，也不能保证社区接受帖子。校验通过且仍有数量不足、图片未完成等警告时，必须保留说明。

运行开发测试：

```sh
python -B -m unittest discover -s tests -v
```

## 能力边界

它不提供私密群访问权限，也没有附带抓取账号、社交发布接口或图片模型。搜索、浏览、图片生成由使用者自己的 AI 环境提供。没有图片工具时会交付方案并标记未生成，不会把方案当成图。

遵守当前社区规则，公开自己与产品的关系，不编造评价，不批量发送同一条广告。发布动作需要使用者明确要求。
